REVEX Android App project

This folder is a ready-to-build Android Studio project that opens the live REVEX HTTPS website.

To create the actual APK:
1. Open this 'android-app' folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. The APK will be generated under app/build/outputs/apk/.

Important:
- This ZIP does NOT contain a pre-built APK. An Android SDK/Gradle build environment is required to produce one.
- The website remains unchanged; this Android app is a separate wrapper.
- Before release, set a proper Android application icon and signing key.
