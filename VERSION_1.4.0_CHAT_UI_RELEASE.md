REVEX 1.4.0 — REVEX AI CHAT UI RELEASE
=========================================

Changes
- Replaced the previous chat presentation with the supplied premium ChatMessages-inspired UI.
- Removed visible Gemini model/provider wording from the frontend chat experience.
- Renamed the visible assistant to REVEX AI.
- Added premium dark chat styling, gradient AI avatar, animated message entrance, typing indicator, blue/purple user bubbles, suggestions and polished composer.
- Preserved the existing REVEX chat API, authentication, conversation history and backend provider configuration.
- Updated package version from 1.3.0 to 1.4.0.

Architecture note
- The supplied project is a vanilla HTML/CSS/JavaScript REVEX frontend, not a React/shadcn/Tailwind/TypeScript project. The UI was integrated natively to avoid replacing the existing working application architecture.
