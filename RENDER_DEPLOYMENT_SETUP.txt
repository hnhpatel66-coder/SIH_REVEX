REVEX 1.9 — LOCAL + RENDER INTEGRATION FIX

WHY LOCAL WORKED BUT RENDER DID NOT
The repository intentionally ignores backend/.env. Local development loads backend/.env, but Render deploys the Git repository and therefore does not receive that file. The previous render.yaml also did not declare the assistant and Mapbox variables. This release declares them as Render secret/environment values with sync:false.

RENDER DASHBOARD (ONE TIME)
Open Render -> your REVEX Web Service -> Environment and add/set:

CHAT_API_KEY=<your Gemini API key>
CHAT_API_URL=
CHAT_API_MODEL=gemini-2.5-flash
MAPBOX_PUBLIC_TOKEN=<your Mapbox pk. token>
MAPBOX_ACCESS_TOKEN=<your Mapbox sk. secret token, optional for server routing/geocoding>
MAPBOX_STYLE_URL=mapbox://styles/mapbox/streets-v12
MAPBOX_GL_VERSION=3.9.4
MAPBOX_COUNTRY=in
SMART_ROUTE_PUBLIC_ROUTER_ENABLED=true
MAPBOX_FALLBACK_ENABLED=true

IMPORTANT
- Do NOT put real secrets into render.yaml, GitHub, or the ZIP.
- CHAT_API_KEY is enough for Gemini; CHAT_API_URL may stay empty.
- MAPBOX_PUBLIC_TOKEN must start with pk. for the browser Mapbox map.
- MAPBOX_ACCESS_TOKEN should be a secret sk. token if you want Mapbox Directions/Geocoding on the server. A pk. token can still render the browser map, but it is not a server secret.
- After changing Environment values, use Save Changes and redeploy/restart the service.

VERIFY AFTER DEPLOY
1. Open https://YOUR-RENDER-DOMAIN/api/health and confirm HTTP 200.
2. Sign in.
3. Open a route page. The map should say Road route by Mapbox when a valid public token is present.
4. Open REVEX Assistant and send a message. It should show Connected/online rather than Setup required.

ROTATE EXPOSED CREDENTIALS
The previous local ZIP contained real-looking MongoDB, Gemini, Razorpay and Mapbox credentials. Treat any credentials that were shared outside your private machine as exposed. Rotate/revoke them in their respective dashboards and replace the Render values with the new credentials. This release does not copy those secrets into the deployment guide.
